# 后端环境配置说明

本文档记录 FastAPI 后端服务的本地开发环境、依赖管理与关键配置，确保团队成员能够快速拉起并保持与镜像环境一致。

## 1. 前置依赖

- Python 3.11（建议使用 `asdf` 或 `pyenv` 管理）
- [uv](https://github.com/astral-sh/uv) 0.8.0 及以上版本（本仓库默认使用 `uv sync` 生成锁文件与虚拟环境）
- Docker 环境（如需复用 `infra` 中的健康检查脚本）

## 2. 目录结构

```
BackEnd/
  app/                # FastAPI 应用源码
  templates/          # 模板仓库，按模板 ID 分目录
  pyproject.toml      # 项目依赖声明
  uv.lock             # uv 生成的锁文件（需纳入版本控制）
  Makefile            # 常用命令封装
```

模板目录示例 `BackEnd/templates/example_contract/`：

- `metadata.json`：模板元数据定义
- `template.docx`：实际 DOCX 模板文件（未随仓库提供，可在本地补充）
- `preview.png`：可选预览图，供前端展示

## 3. 依赖管理流程

1. 首次克隆仓库或新增依赖前运行：

   ```bash
   cd BackEnd
   uv sync
   ```

   该命令会自动创建 `.venv` 虚拟环境并生成/更新 `uv.lock`。

2. 新增依赖：

   ```bash
   uv add fastapi
   ```

   所有依赖必须写入 `pyproject.toml` 并在 `uv.lock` 中固化，提交代码时同时提交两者。

3. 更新依赖：

   ```bash
   uv lock --upgrade fastapi
   ```

4. CI/CD 或容器内可统一使用：

   ```bash
   uv sync --frozen
   ```

   `--frozen` 确保严格按照锁文件安装，避免出现未锁定的版本变动。

## 4. 环境变量与配置

后端配置由 `app/core/config.py` 中的 `Settings` 管理，支持从 `.env` 文件或系统环境注入，变量前缀为 `BACKEND_`。常用配置如下：

- `BACKEND_ENVIRONMENT`：运行环境标识，如 `development`、`staging`。
- `BACKEND_LOG_LEVEL`：日志等级，默认 `INFO`。
- `BACKEND_TEMPLATE_ROOT`：模板根目录，默认为仓库内 `BackEnd/templates`。
- `BACKEND_TASK_EXPIRY_MINUTES`：任务默认过期时间（分钟）。

示例 `.env`：

```
BACKEND_ENVIRONMENT=development
BACKEND_LOG_LEVEL=DEBUG
BACKEND_TEMPLATE_ROOT=/opt/app/templates
```

## 5. 日志与健康检查

- 日志由 `loguru` 管理，以结构化格式输出到标准输出，默认等级 `INFO`。可通过 `BACKEND_LOG_LEVEL` 调整。
- `/health` 接口提供版本、环境与时间戳信息，便于基础监控。
- `Makefile` 中的 `healthcheck` 命令复用 `infra/scripts/healthcheck.sh`，确保与镜像脚本一致。

## 6. 常用命令

在 `BackEnd` 目录下执行：

```bash
make sync             # 执行 uv sync
make dev              # 以热重载方式启动 FastAPI
make run              # 以生产模式启动 uvicorn
make test             # 运行 Pytest（预留）
make healthcheck      # 运行镜像健康检查脚本
make refresh-templates # 手动刷新模板缓存
```
